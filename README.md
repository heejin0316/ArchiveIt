# 아카이브잇 (ArchiveIt)

사용자가 직접 로그인해 정상적으로 연 이화이언 족보 상세 게시글의 본문과 이미지를 PDF로 저장하는 Chrome 확장 프로그램입니다.

> 아카이브잇은 이화이언의 공식 서비스가 아니며, 이화이언과 제휴하거나 이화이언을 대리하지 않습니다.

> 아카이브잇은 사용자가 정상적으로 열람할 권한이 있는 족보 게시글을 개인적인 학습·보관 목적으로 저장하도록 돕습니다. 접근 제한을 우회하거나 콘텐츠를 외부 서버로 전송하지 않으며, 저장물의 무단 공유·재배포·공개 게시·판매 또는 상업적 이용을 지원하지 않습니다.

## 주요 기능

- 족보 게시글의 본문과 첨부 이미지를 하나의 PDF로 저장
- 본문의 문단, 굵기, 기울임, 밑줄 등 서식 유지
- 게시글 제목을 PDF 파일명으로 사용
- 첨부 이미지 순서 유지
- 초장축 이미지를 A4 여러 페이지로 자동 분할
- 텍스트와 이미지가 함께 있는 글을 읽기 좋은 문서 흐름으로 배치
- 외부 서버, 사용자 계정, 분석 도구 없이 브라우저 내부에서 처리
- PDF 변환 성공 횟수가 10의 배수가 될 때마다 학습 응원 메시지 표시

## 설치

### Chrome Web Store

Chrome Web Store 등록을 준비하고 있습니다. 등록이 완료되면 이 항목에 공식 설치 링크를 게시합니다.

### 개발자 모드

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 우측 상단의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. 이 프로젝트 폴더를 선택합니다.

## 사용 방법

1. 사용자가 직접 이화이언에 로그인합니다.
2. 족보 상세 게시글을 엽니다.
3. 아카이브잇 확장 아이콘을 누릅니다.
4. **PDF로 저장**을 누릅니다.
5. Chrome 인쇄 창에서 **PDF로 저장**을 선택합니다.

## 이용 시 유의사항

- 본인이 정상적으로 열람할 권한이 있는 게시글에만 사용하세요.
- 저장한 콘텐츠는 관련 서비스 약관과 저작권을 준수하여 개인적인 학습·보관 범위에서 이용하세요.
- 아카이브잇은 로그인, 학생 인증 또는 기타 접근 제한을 우회하지 않습니다.
- 게시글 작성자와 권리자의 허락 없이 저장물을 공유, 재배포, 공개 게시, 판매하거나 상업적으로 이용하지 마세요.

## 개인정보 보호

아카이브잇은 PDF 생성을 위해 현재 게시글의 웹사이트 콘텐츠를 사용자의 기기에서 처리합니다. 개인정보, 게시글 본문 또는 이미지를 개발자 서버로 수집하거나 전송하지 않습니다. 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 확인하세요.
